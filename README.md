## How to run
```bash
javac *.java
java Main
```

## Features that work

1. Add and manage books with Book ID, title, author and copy count.
2. Register and manage library members.
3. Issue books while checking availability and member borrowing limits.
4. Return books and automatically calculate late fines.
5. Search books by title or author.
6. View overdue books with member details.
7. Manage book reservations for members.
8. Notify members when their reserved books become available.
9. Maintain transaction history.
10. Store book, member and transaction records using Java Serialization.
